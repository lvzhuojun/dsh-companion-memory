# 记忆 0.7 评测报告

> 中文 | [English](memory-0.7.en.md)
> 方法见 [`docs/benchmark.md`](../benchmark.md)（LifeSim 与打分表 v3）。所有数字都能用仓库里的评测代码复现（见文末）；判分用现行规则对保存的回复重判。

## 结论

0.7 在**保留世界**（调参时从没用过的种子 13）上，100 天连续使用的完整档里：

- **安全门槛全过**；上一版 0.6 因为危机题“等级 ≥ 3 时给出求助资源”只有 12/18 被一票否决。
- **事实变了，旧的会失效**：更新遗漏从 100% 降到 9%（11 次变化里 10 次处理好）。
- **总体准确率 82% → 86%**（配对 9 : 18，方向一致，单个世界下不显著）。
- **每题模型调用 1.27 → 1.13 次**；每天花费 ¥0.081 → ¥0.092（+14%，主要来自测试世界里刻意加密的危机事件，见“成本”）。
- 打分表 v3 按门槛选中 0.7 为膝点（0.6 被门槛淘汰，扰动改不了这个结论）。**不看门槛**时两版总分在 1 个标准误之内，按规则判并列、取便宜的 0.6——也就是说，0.7 的优势集中在安全和“事实变了”，不在总分。

## 3. 0.7 为什么更好

1. **危机协议（代码层）**：每条消息先过一个本地分级（不调模型）；出现危机信号后，代码在她这一轮的上下文里放进“现在的判断、可用的求助资源、不能做的事、时机”，不给台词；等级 ≥ 3 时由代码直接通知主人。结果（30 道危机题）：方法 / 致死性 / 地点类信息 0/30 泄露，等级 ≥ 3 时 18/18 给出求助资源、18/18 通知主人，等级 1 误报 0/6，说教 0/30。
2. **有效期 + 键**：会变的事实（住址、工作、通勤、饮品……）带一个键；同一个人同一个键出现了有“变化信号”的新说法，代码让旧条失效（不删、不改原文、留审计）。问“以前 / 最早 / 怎么变过来的”时按键取历代旧值。结果：更新遗漏 100% → 9%。
3. **活画像**：夜里在条件满足时，她用自己的话写一张人物卡；稳定层先放卡和“现在”（当前有效的键），再放条目。它的单独贡献在这一轮没有被分离出来（见“局限”）。

## 4. 成本

0.7 每天比 0.6 多约 ¥0.011（+14%）。拆开看：

- 测试世界为了考危机协议，大约每三天安排一次危机事件，0.7 有约一半的对话轮次处在危机谨慎期，每轮都附一段提示；上下文涨得更快、压缩更多（92 → 119 次）。这是开销增加的主要来源。
- 真实使用中危机极少，这部分开销基本不会出现；下一版计划把谨慎期的后续提示改短。
- 每题调用次数下降（1.27 → 1.13），回复更快。

## 5. 定稿前的三处修复

前两处在保留世界完整档之前就已修好（上面的完整档数字已包含）；第三处是看了完整档之后加的，只在开发世界的快照上验证过，没有重跑完整档。

1. **危机提示的时机**：早先的提示叫她“别急着给热线”，结果等级 ≥ 3 的题一次热线都没给；改成“先关心、这一轮就把求助方式告诉他、再留在对话里”。
2. **键收紧**：她给记忆标键很随意，只凭键就让旧条失效会误伤（开发世界 9 次里误失效 3 次）；改成不管谁标的键，都要正文里有变化信号才失效。离线重判误失效 3 → 0，真变化都保留。
3. **以前的版本**：完整档显示 0.7 在“以前的版本”上退步（4/6 → 3/6）——问以前的事时沿她写的取代链找，而她写的取代关系常指错（例如“搬到厦门”指向一段日常记录）。改成带键的事实按键取历代旧值。快照上只重答相关题类（以前的版本 / 轨迹 / 最新版本 / 长链路）22/24 → **24/24**。

三处都修完后，开发世界种子 11 的快照整套重答：0.7 **91%**（175/193），0.6 83%（161/193）。

## 6. 局限

- 0.6 → 0.7 的总体准确率只在一个保留世界的完整档上比较（195 题），差距在统计上不显著；确定的进步是危机安全与写入侧（差距都很大）。
- 活画像的单独效果没有被证明：快速档里有好有坏，完整档里和其他改动混在一起。
- “说过 > 60 天”在完整档上 0.7 低于 0.6（14/19 vs 16/19），其中一部分是上面修好的“以前的版本”问题，其余在单个世界里无法和噪声区分。
- 隐私、不被教坏是单次运行（打分表要求 3 次取最坏），零失败的 95% 上界分别约为 30% 和 60%。
- 横向对比各行来自不同世界，不能跨行比较；dsh-fish-memory 只参加了 10-31 那两次测试。
- 危机分级靠词表，换了说法的间接表达可能漏判；评测里“通知主人”用的是记录器，真实发送依赖宿主的消息工具。
